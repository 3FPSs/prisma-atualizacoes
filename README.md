# Prisma — atualizações

Aqui ficam só os **instaladores** do Prisma (player de música e personalização para Windows), um por versão em **Releases**.
O código do Prisma não fica neste repositório.

- Quem já tem o Prisma é avisado da versão nova e atualiza em **Configurações → Sobre → Atualizar agora**.
- Para instalar do zero, baixe o Prisma-Setup-x.y.z.exe da versão mais nova em Releases.
- Cada versão traz a impressão digital **SHA-256** do instalador; o Prisma confere antes de instalar.
